# Sistem Informasi Biodata Mahasiswa Advance (Airtable Theme)

Implementasi sistem informasi biodata mahasiswa menggunakan Native PHP, MySQLi Prepared Statements, Tailwind CSS CDN, AJAX Live Search, GIS Leaflet.js, dan SheetJS.

## Fitur
- Otentikasi & Authorization Role-based
- CRUD Lengkap Mahasiswa & Soft Delete
- Audit Logging setiap perubahan data
- Live AJAX Search & Filter
- Visualisasi GIS Sebaran Domisili
- Ekspor Spreadsheet XLSX
- Desain KTM Digital

## Setup & Instalasi
1. Pastikan server Apache & MySQL aktif di XAMPP.
2. Impor `database.sql` ke MySQL.
3. Jalankan aplikasi melalui browser di `http://localhost/sistemDataMahasiswa/`.
