Arsitektur: Native PHP 8+ (OOP/Procedural Modular), MySQLi Prepared Statements, CSS via Tailwind CDN. Tidak ada framework backend.

Milestone 1: Fondasi (DB & Auth) — Setup database.sql dengan dummy data, relasi tabel, file koneksi.php, dan sistem login role-based (Admin vs Mahasiswa).

Milestone 2: CRUD & Soft Delete — Implementasi operasi tambah, edit, soft delete, dan tampilkan data. Validasi server-side dan penulisan otomatis ke tabel audit_logs.

Milestone 3: Advanced UI (AJAX & File) — Integrasi Live Search, Filter silang (Prodi & Status), Pagination via Fetch API, dan unggah multi-berkas (Gambar foto & PDF dokumen) dengan validasi tipe biner.

Milestone 4: Integrasi Pihak Ketiga & Export — Peta Leaflet.js menggunakan latitude/longitude, Ekspor data Excel via SheetJS, dan halaman cetak KTM dengan QR Code (qrcode.js).

Milestone 5: API Endpoint — Pembuatan api/mahasiswa.php untuk merender JSON murni.
